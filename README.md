# DiffLoop

`DiffLoop` identifies differential chromatin loops between two experimental conditions using Hi-C contact counts, expected contact frequencies, and DESeq2.


## Installation

Clone the repository:

```bash
git clone https://github.com/BenxiaHu/DiffLoop.git
cd DiffLoop
```

Create the conda environment:

```bash
conda env create -f environment.yml
conda activate diffloop
```

Install `DiffLoop`:

```bash
pip install .
```

After installation, the command can be called from any directory:

```bash
DiffLoop --help
```

## Input files

### 1. Chromatin loop file

Provide a BEDPE-like tab-separated file containing the first six columns:

```text
chrom1    start1    end1    chrom2    start2    end2
```

For example:

```text
chr1    100000    105000    chr1    250000    255000
chr1    300000    305000    chr1    500000    505000
```

Currently, `DiffLoop` analyzes intra-chromosomal loops.

### 2. Sample information file

Provide a tab-separated `samples.tsv` file with the following columns:

```text
sample    mcool_path    resolution    expected_path
```

Example:

```text
sample	mcool_path	resolution	expected_path
Control_rep1	/path/to/Control_rep1.mcool	5000	/path/to/Control_rep1_expected.tsv
Control_rep2	/path/to/Control_rep2.mcool	5000	/path/to/Control_rep2_expected.tsv
LPS_rep1	/path/to/LPS_rep1.mcool	5000	/path/to/LPS_rep1_expected.tsv
LPS_rep2	/path/to/LPS_rep2.mcool	5000	/path/to/LPS_rep2_expected.tsv
```

- `sample`: sample name
- `mcool_path`: path to the `.mcool` file
- `resolution`: Hi-C resolution used for loop analysis
- `expected_path`: path to the expected-contact file generated by `cooltools expected-cis`

### 3. Expected-contact files

Expected contact frequencies can be generated using `cooltools expected-cis`.

The expected file must contain either:

```text
region1    region2    dist_bp    count.avg
```

or:

```text
chrom1    chrom2    dist_bp    count.avg
```

## Usage

`DiffLoop` provides a single command-line interface for the differential loop analysis workflow.

### Run the complete analysis

```bash
DiffLoop run \
    --samples examples/samples.tsv \
    --loops loops.bedpe \
    --treatment LPS \
    --control Control \
    --treatnum 2 \
    --ctrlnum 2 \
    --outdir results \
    --prefix LPS_vs_Control \
    --log2fc 1 \
    --padj 0.05
```

This command performs two steps internally:

1. Extract raw contact counts for each chromatin loop from the `.mcool` files and generate the normalization-factor matrix using expected contact frequencies.
2. Run the bundled DESeq2 analysis to identify differential chromatin loops.

Users do not need to run `counts.py` or `deseq2.R` directly.

## Main options

| Option | Description |
| --- | --- |
| `--help` | Show the help message and exit |
| `--inputpath` |  Directory containing the input files |
| `--input` | Sample information file (tab-separated columns: `sample`, `mcool_path`, `resolution`, `expected_path`) |
| `--loops` | BEDPE-like chromatin loop file |
| `--Treatid` | Treatment sample prefix |
| `--Ctrlid` | Control sample prefix |
| `--Treatnum` | Number of treatment replicates |
| `--Ctrlnum` | Number of control replicates |
| `--outfile` | Output file prefix |
| `--outdir` | Output directory |
| `--prefix` | Prefix for output files |
| `--log2fc` | Absolute log2 fold-change cutoff; default: `1` |
| `--padj` | Adjusted P-value cutoff; default: `0.05` |

To see all available options:

```bash
DiffLoop run --help
```

## Output

The counting step generates:

```text
<prefix>_rawcounts.txt
<prefix>_normalizationFactor.txt
```

The DESeq2 step then generates differential-loop results using the specified fold-change and adjusted P-value thresholds.

For example:

```text
results/
├── LPS_vs_Control_rawcounts.txt
├── LPS_vs_Control_normalizationFactor.txt
```
